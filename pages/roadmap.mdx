# Roadmap (Rebased and Measurable)

This roadmap replaces date ranges from 2023-2024 with phased milestones tied to verification criteria.

## Phase 1 — Foundation Hardening

- Freeze and review current smart contract interfaces
- Verify VRF draw pipeline end-to-end in staging
- Normalize docs and naming across Junglebook and Loro App

**Exit criteria**

- No critical findings open from internal review
- Staging draw flow executed successfully 10 times in a row
- Public docs and app naming are consistent

## Phase 2 — Production Readiness

- Publish benchmark dashboard for transaction success and draw auditability
- Add runbooks for incident response and draw operations
- Complete external security review for lottery and rewards logic

**Exit criteria**

- Benchmark dashboard publicly accessible
- Incident runbook approved by maintainers
- External review issues triaged and resolved by severity target

## Phase 3 — Controlled Growth

- Enable phased user onboarding with monitored wallet cohorts
- Launch conservation reporting page with quarterly updates
- Expand partner integrations only after reliability SLOs hold

**Exit criteria**

- 90-day reliability target met (99.5% successful core flows)
- First quarterly conservation report published
- Post-launch retrospective completed with action items

## Phase 4 — Ecosystem Expansion

- Introduce additional game/lottery mechanics behind feature flags
- Evaluate multi-chain or L2 expansion from usage and cost data
- Formalize governance process for token-related upgrades

**Exit criteria**

- Feature-flag telemetry shows stable adoption without regression
- Expansion proposal approved with risk assessment
- Governance workflow documented and tested
