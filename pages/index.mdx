# Junglebook: Pandemonium Documentation Overview

Junglebook is the documentation preamble for **Pandemonium / Loro App**. This edition replaces aspirational claims with measurable targets, explicit assumptions, and clear delivery gates.

## Scope

Pandemonium combines:

- A 4,200-item macaw-themed NFT collection
- A lottery mechanism with verifiable randomness
- A reward token model for participation incentives
- A conservation funding commitment linked to on-chain activity

## Operating Assumptions

- Core network support remains EVM-compatible.
- Third-party services (VRF, indexers, RPC providers) are external dependencies.
- Product delivery prioritizes security and user safety over launch speed.

## Realistic Benchmark Targets (12-Month Window)

| Area | Target | Success Criteria |
| --- | --- | --- |
| Contract reliability | 99.5%+ successful user transactions | Measured across mint, claim, and lottery calls |
| Lottery integrity | 100% auditable winner selection events | Every draw linked to public randomness proof |
| User performance | p95 frontend route load under 2.5s on 4G | Measured on mint, reward-claim, and lottery-entry user journeys |
| Community growth | 1,500+ verified wallet participants | Unique active wallets over rolling 90 days |
| Conservation impact | Publish quarterly donation ledger | Amount, recipient, and transaction references |

## Integration Note for Loro App

Junglebook should be exposed in Loro App navigation as:

- **Label:** `Junglebook`
- **Type:** external docs link
- **Destination:** the deployed Junglebook docs home URL

This keeps product flows in-app while preserving whitepaper and roadmap context in a dedicated docs surface.
